jalt is an addon for World of Warcraft (retail) that tracks the inventory of all characters, bank slots, warband bank, etc. It's inspired by Altoholic, but implements far fewer features and uses none of its code.

If you happen upon this, you are welcome to use it subject to LICENSE, but I will not be tracking issues, accepting PRs, or monitoring forums about it.

# Usage

`/jalt` - Bring up the main window. It has tabs to show gear equipped on each alt and currency.
`/jalt search <pattern>` - Search for all items matching `<pattern>`, e.g. `/jalt search fur` searches for all items that have "fur" in the name.

Tooltips are updated with location and counts of all scanned items.
